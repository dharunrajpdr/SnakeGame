# 🐍 Snake Game

A simple browser-based Snake Game built with **HTML, CSS and JavaScript**.

## Features
- Arrow key and WASD controls
- Score and high score
- High score saved with localStorage
- Collision detection
- Restart button
- Responsive layout
- No external libraries required

## Play Online

After GitHub Pages is enabled, the game will be available at:

https://dharunrajpdr.github.io/SnakeGame/

## Run Locally

Open `index.html` in a browser.

## Controls

- ⬆️ / W — Up
- ⬇️ / S — Down
- ⬅️ / A — Left
- ➡️ / D — Right
- Space — Restart after Game Over
